# Stakeholder Validation

This validation record is a student / stakeholder exercise, not evidence from a live production deployment. Three hypothetical testers were asked whether the dashboard was understandable, whether fairness was easy to interpret, whether the baseline comparison was useful, whether assignment reasons were clear, and whether the product would help during disruptions.

| Role | Average score | Most useful feature | Main concern | Suggested improvement |
|---|---:|---|---|---|
| Operations Manager | 4.6 / 5 | Baseline comparison | Bulk reassignment flow | Add shift handoff export |
| Dispatch Supervisor | 4.4 / 5 | Explainability drawer | Route-level alerts | Add map overlay and escalation rules |
| Rider | 4.1 / 5 | Workload transparency | Earnings assumptions | Show payout policy alongside balance |

Aggregate summary: 3 users tested, average usability score 4.4 / 5, most useful feature explainability, and the main concern is the need for richer route-level context before production rollout.
